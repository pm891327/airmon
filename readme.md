# Airmon Industries

## Descripción del proyecto

Airmon Industries es un proyecto de tienda online especializada en hardware orientado a la ciberseguridad y al hacking ético. La plataforma permitirá consultar productos, conocer sus características y acceder a información sobre cursos formativos relacionados con cada dispositivo.

El proyecto también contempla el diseño y la simulación de la infraestructura de red de una tienda física mediante una herramienta de simulación de redes.

## Objetivos

- Desarrollar una tienda web funcional.
- Diseñar una base de datos para gestionar productos, usuarios y pedidos.
- Implementar un catálogo de hardware y una sección preparada para integrar cursos formativos.
- Diseñar y documentar la infraestructura de red de la tienda física.
- Aplicar buenas prácticas de desarrollo, administración de sistemas y documentación técnica.

## Alcance previsto

- Tienda online y catálogo de productos.
- Carrito y proceso de compra.
- Base de datos y backend.
- Sección de cursos preparada para futuras ampliaciones.
- Simulación de red con Packet Tracer o GNS3.
- Memoria técnica del proyecto.
